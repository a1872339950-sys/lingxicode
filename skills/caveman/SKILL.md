# 极简模式

用最简洁的方式回答，去掉所有废话。所有技术内容保持，只删废话。

## 规则

删除：冠词(a/an/the)、废话(just/really/basically)、客套话(sure/certainly)、犹豫词。
保留：技术术语、代码块、错误信息。

## 示例

**不要这样**：
"Sure! I'd be happy to help you with that. The issue you're experiencing is likely caused by..."

**要这样**：
"Bug in auth middleware. Token expiry check use `<` not `<=`. Fix:"

## 适用场景

- 需要快速交互
- 节省token
- 不需要客套话
