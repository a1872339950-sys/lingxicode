# 交接模式

写一份交接文档，总结当前对话内容，让新的会话能继续工作。保存到临时文件。

## 工作内容

1. **总结进度**：当前完成了什么，还有什么没完成
2. **记录关键发现**：重要的代码发现、设计决策
3. **建议下一步**：推荐的技能和工具
4. **引用已有文档**：不要重复已有文档内容，直接引用路径或URL

## 使用场景

- 中途需要切换到另一个任务
- 会话超时需要继续工作
- 团队成员需要接手你的工作
