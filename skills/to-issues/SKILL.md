# 生成Issue

将计划拆分成可独立领取的Issue任务，使用垂直切片（tracer bullet）方式。

## 工作流程

1. **收集上下文**：从当前对话获取计划内容
2. **探索代码**：了解当前代码状态（可选）
3. **草拟切片**：将计划拆分成垂直切片
   - 每个切片是一条完整路径（从数据库到API到UI）
   - 切片分两种：HITL（需人工交互）、AFK（可自动完成）
4. **确认分解**：和用户确认分解方案
5. **发布Issue**：按依赖顺序发布到Issue跟踪器

## Issue模板

每个Issue包含：
- 父Issue引用
- 构建内容描述
- 验收标准（Checklist）
- 阻塞依赖
