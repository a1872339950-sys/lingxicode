# 创建技能

帮助用户创建新的技能文件。

## 工作流程

1. **收集需求**：询问用户
   - 技能覆盖什么任务/领域？
   - 需要处理什么具体场景？
   - 需要可执行脚本还是只需要指令？

2. **草拟技能**：创建
   - SKILL.md（简洁指令）
   - 参考文件（如果内容超过500行）
   - 工具脚本（如果需要确定性操作）

3. **和用户确认**：展示草稿并询问
   - 是否覆盖了你的场景？
   - 有缺失或不清楚的地方吗？
   - 需要更详细还是更简洁？

## 技能结构

```
skill-name/
├── SKILL.md           # 主要指令（必须）
├── REFERENCE.md       # 详细文档（可选）
├── EXAMPLES.md        # 使用示例（可选）
└── scripts/           # 工具脚本（可选）
```

## SKILL.md模板

```md
---
name: skill-name
title: 技能名称
description: 简要描述。当[具体触发词]时使用。
---

# 技能名称

## 快速开始

[最简示例]

## 工作流程

[复杂任务的步骤清单]

## 高级功能

[链接到其他文件]
```
