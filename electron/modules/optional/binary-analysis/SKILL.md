# 二进制分析（可选模块）

## 何时使用

- 用户提供 `.exe` / `.dll` / `.so` 等路径，并说明是自有构建、授权样本或隔离研判
- 能力开关 **二进制分析** 已开启

## 何时拒绝

- 明确要求破解商业软件授权、绕过 DRM、制作恶意软件
- 用户未开启能力开关

## 流程

1. 确认路径与授权语境（用户提供 + 开关开启即可）
2. 调用 `inspect_binary`，以工具结果为准
3. 解读：格式/架构、导入 DLL、高熵节、可疑字符串、入口预览
4. 需要伪代码时：说明需本机 Ghidra/r2，本模块不做完整反编译

## 禁止

- 未调工具仅口头拒绝（开关已开且路径明确时）
- 把结果说成「已完整反编译」
