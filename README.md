# 灵犀 LingXiCode

灵犀是一个基于 Electron 的桌面 AI 工作空间，提供多模型配置、项目会话、工具调用、上下文管理、资源中心和本地开发辅助能力。

## 功能概览

- **多模型与多项目会话**：可配置不同模型服务，并按项目、分支和会话组织任务。
- **多模态与视觉模型接力**：支持图片附件和视觉理解；当前模型没有视觉能力时，可调用已配置的视觉模型分析图片，再把分析结果交给当前模型继续处理。
- **模型能力调度**：可按视觉理解、文生图、音乐、视频和语音等能力设置模型优先级。
- **画布工作流**：通过输入、工作和输出节点组织任务，支持创建、编辑、连线、模型分配与项目内保存。
- **本地工具执行**：提供文件、终端、浏览器、桌面、Office、Blender 等工具，并配有权限控制和操作记录。
- **上下文与长期任务管理**：提供 Token 用量、上下文压缩、项目记忆、执行备忘录和恢复点。
- **媒体与可视化输出**：支持图片、音频、视频生成工具，以及对话内嵌图表和流程可视化。
- **开放扩展**：支持 Skill、MCP 和插件扩展。

## 当前状态与已知不足

LingXiCode 仍处于持续开发阶段，更适合体验、研究和二次开发，目前还不是所有功能都稳定的成熟产品。

- **浏览器功能尚未完成**：基础网页访问和部分交互已经可用，但复杂登录、OAuth、弹窗、下载、文件协议和不同网站的兼容性仍可能出现问题。
- **聊天历史仍需完善**：超长会话、项目或会话切换、执行中断后的恢复，以及消息顺序、滚动位置和运行块还原仍有边界问题。重要内容请自行备份。
- **远程遥控仍是早期实现**：目前主要面向局域网配对和基础消息同步，移动端适配、断线重连、后台稳定性、权限边界和安全加固尚未完成，请勿直接暴露到公网。
- **桌面操控准确性有限**：Electron、Chromium 和自绘界面的可访问性信息可能不完整；坐标点击也会受到窗口遮挡、缩放和界面变化影响，关键操作需要人工确认。
- **画布工作流仍在迭代**：节点创建、编辑和保存已经具备，但复杂调度、失败恢复、并发执行和完整的运行反馈还需要继续完善。
- **模型与媒体接口存在兼容差异**：不同服务商或中转服务对流式响应、工具调用、图片、音频和视频接口的实现不完全一致，部分组合可能需要单独适配。
- **当前主要面向 Windows**：其他操作系统尚未进行完整适配和验证。

## 环境要求

- Windows 10 或 Windows 11
- Node.js 20 或更高版本
- npm 10 或更高版本
- Git

部分桌面控制、Office、Blender 或自研安装器能力需要对应的本机软件。未安装这些软件不会影响基础聊天界面启动。

## 本地运行

Windows 用户可以直接双击：

```text
一键启动开发版.bat
```

脚本会检查 Node.js 和 Electron。首次运行会自动执行 `npm ci`；如果启动失败，窗口不会立即消失，并会在项目根目录生成 `startup-error.log`。

也可以使用命令行：

```powershell
git clone https://github.com/a1872339950-sys/lingxicode.git
cd lingxicode
npm ci
npm start
```

模型配置在应用设置中完成。不要把 API Key 写入源码或提交到 Git。

## 代码检查

```powershell
npm run check
npm run test:scenarios
```

场景测试可能创建临时目录；这些目录已通过 `.gitignore` 排除。

## 普通打包

```powershell
npm run pack
```

默认输出到项目根目录的 `dist/`。

## 自研安装器

```powershell
npm run dist:self
```

默认临时产物写入 `.installer-build/`。也可以指定外部目录，避免让项目目录膨胀：

```powershell
$env:LINGXI_INSTALLER_OUTPUT = 'E:\LingXiBuild'
npm run dist:self
```

安装器还需要 .NET Framework 编译器和 WebView2 程序集。如果 WebView2 不在脚本的默认检测位置，可设置：

```powershell
$env:LINGXI_WEBVIEW2_DIR = 'D:\path\to\WebView2\assemblies'
$env:LINGXI_WEBVIEW2_LOADER = 'D:\path\to\WebView2Loader.dll'
npm run dist:self
```

## 本地数据

运行后产生的数据默认属于用户本机数据，不应提交：

- `data/`：项目、会话、摘要、Token 用量和生成资源
- `.lingxi/`：运行时备忘录与可视化
- `change-sessions/`：改动会话
- `output/`：生成输出
- `config/*.json`：本机配置；示例配置除外

提交代码前建议执行：

```powershell
git status --short
git grep -n -E 'sk-[A-Za-z0-9_-]{20,}'
```

## 模型服务配置

模型服务在应用设置中由用户自行配置。请使用自己有权访问的模型服务与密钥，并遵守对应服务商条款。

设置中的 Token 用量页面用于统计当前设备产生的用量。
