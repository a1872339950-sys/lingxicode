# 2D 角色动画 QA

## 必须通过

- 同一角色在所有动作中身份一致（脸、比例、配色、道具、风格）
- 每帧主体完整，不裁切肢体；透明背景干净
- 动作可读：不看文件名也能大致认出状态
- 循环动作首尾衔接无明显跳变（除非用户要求 one-shot）
- 帧尺寸在同一动作内一致（除非用户要求可变包围盒）
- 输出在**项目内**约定目录，路径写进 `character.json`

## 建议检查

- contact sheet 总览
- 每动作预览 GIF / 序列播放
- 左右走镜像是否反时间轴
- 过小细节在目标显示尺寸是否糊成一团

## 失败即返工

- 动作间换了物种/服装/主色
- 白底/棋盘格/阴影地块残留
- 文字、UI、网格线进帧
- 文件写到与项目无关的路径
