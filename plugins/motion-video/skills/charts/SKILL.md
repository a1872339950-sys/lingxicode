# 数据动效

## 原则

1. **数据为 props**，方便改数重导  
2. 动画表达「变化」：生长、对比、高亮当前系列  
3. 坐标轴与标签在运动中仍可读  
4. 颜色系列固定，不每帧换色  

## 推荐模式

- 柱：高度从 0 插值到目标  
- 折线：路径长度或点逐个显现  
- 饼：角度扫出  
- 数字：整数插值到目标值  

## 检查

- [ ] 最终帧数值正确  
- [ ] 图例/单位齐全  
- [ ] 总时长匹配叙事（常见 8–20 秒）
