# 音频与节奏

## 原则

1. 音乐服务画面，不盖过口播  
2. 音量用曲线（淡入淡出），避免咔哒  
3. 卡点：鼓点/重音对齐关键字幕或图表峰值帧  
4. 音效短而稀疏  

## 工程注意

- 资源放 `public/`，路径稳定  
- 先确认时长，再定 Composition 总帧  
- 需要裁剪/转码可用系统 ffmpeg（灵犀项目常内嵌 ffmpeg 安装器）  

## 检查

- [ ] 预览有声且不破音  
- [ ] 片头片尾淡出干净  
- [ ] 无音频时片长仍完整  

详见 `references/audio.md`。
