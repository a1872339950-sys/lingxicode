# 办公文档库

灵犀插件：在**项目/本地目录**中发现、摘要、安全编辑 Office 存量文件。

## 与「办公模板」的区别

| 办公文档库 | 办公模板 |
|------------|----------|
| 改已有文件 | 从模板新建 |
| 先发现再编辑 | 先选模板再填充 |
| 强调整文件回写与版式保真 | 强调参考版式起稿 |

## 技能

- `index` 总路由
- `discover` 发现文档
- `word-docs` Word
- `spreadsheets` Excel
- `formula-builder` 公式
- `powerpoint` PPT
- `shared-docs` 跨文档维护
