# 工程交付工作流

灵犀官方插件：把「计划 → 实现 → 排错 → 验证 → 交接」收成一个可安装能力包。

## 包含流程

| 子 Skill | 用途 |
|----------|------|
| `index` | 总入口：按任务类型路由到合适阶段 |
| `write-plan` | 多步任务先写可执行计划 |
| `systematic-debug` | 报错/异常先复现取证再修 |
| `tdd` | 测试驱动：红 → 绿 → 重构 |
| `verify-before-done` | 宣称完成前跑可执行验证 |
| `handoff` | 会话中断时写交接文档 |

## 使用

1. 资源中心 → 能力 → 插件商城 → 安装 **工程交付工作流**
2. 输入框选用该插件（聚合入口）
3. 或直接说试用句，例如：
   - 我想加一个功能，帮我按工程流程推进
   - 这个 bug 怎么系统性排查再修
   - 功能差不多了，帮我做完成前验证再收口

## 设计原则

- 对用户谈阶段与结果，不堆工具说明书
- 未确认计划前尽量只读取证
- 不把「搜了很多文件」当成验证
- 主会话自己读流程说明，不派子代理代读 skill
