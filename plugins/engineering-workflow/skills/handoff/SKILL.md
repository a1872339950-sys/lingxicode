# 交接

写一份交接说明，让下一会话能继续工作。优先写到项目内约定目录或用户指定路径；未指定时可写到项目临时说明文件并告知路径。

## 内容

1. **进度**：已完成 / 未完成  
2. **关键发现**：代码位置、设计决策、坑  
3. **建议下一步**：推荐流程（如排错 / 验证）与入口  
4. **引用已有文档**：路径即可，不重复长文  

## 场景

- 中途切换任务  
- 会话过长需要续作  
- 需要他人接手  

## 输出要求

- 短、可执行、带路径与命令线索  
- 标明「未验证」项，避免接手前盲目宣称完成
