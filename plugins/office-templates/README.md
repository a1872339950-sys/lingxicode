# 办公模板

灵犀插件：从**参考模板**新建文档、演示、表格。

## 定位

| 是 | 否 |
|----|----|
| 项目内新建 `.docx` / `.pptx` / `.xlsx` | 连接企业 SharePoint |
| 以 `templates/` 参考文件保版式 | 强制改你的库存量文件 |
| 走 `artifact_workflow` / `office_workflow` 与 python 脚本 | 假装在线单元格级云编辑 |

## 模板

见 `skills/index/SKILL.md` 与 `references/catalog.md`。

## 重建参考文件

```bash
python scripts/build_references.py
```
