# 模板目录

| ID | 类型 | 显示名 | 参考文件 | 用途 |
|----|------|--------|----------|------|
| minimal-letterhead | document | 商务信笺 | templates/minimal-letterhead.docx | 正式信件 |
| strategy-memorandum | document | 战略备忘录 | templates/strategy-memorandum.docx | 决策建议 |
| system-design | document | 系统设计 | templates/system-design.docx | 架构说明 |
| design-report | document | 设计报告 | templates/design-report.docx | 设计方案 |
| team-alignment | presentation | 团队对齐 | templates/team-alignment.pptx | 规划对齐会 |
| project-kickoff | presentation | 项目启动 | templates/project-kickoff.pptx | Kickoff |
| business-review | presentation | 业务复盘 | templates/business-review.pptx | 复盘汇报 |
| simple-light | presentation | 简约演示 | templates/simple-light.pptx | 通用轻演示 |
| analytics-dashboard | spreadsheet | 分析看板 | templates/analytics-dashboard.xlsx | 指标看板 |
| financial-budget | spreadsheet | 财务预算 | templates/financial-budget.xlsx | 季度预算 |
| project-tracker | spreadsheet | 项目跟踪 | templates/project-tracker.xlsx | 任务跟踪 |
| three-statement-forecast | spreadsheet | 三表预测 | templates/three-statement-forecast.xlsx | 损益/资产负债/现金流 |

## 默认输出

```text
<project>/assets/office/<template-id>-<short-slug>.(docx|pptx|xlsx)
```

用户指定路径时以用户为准。
