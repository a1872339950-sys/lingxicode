# 灵犀 LingXiCode 产品介绍

## 一句话定位

**灵犀 LingXiCode**：一款面向中文用户的 AI 智能编程助手，真正能操作项目、可控执行、国内优化。

---

## 为什么做灵犀？

Claude Code、Cursor、OpenAI Codex 都是优秀的产品，但它们有一个共同问题：

**它们是为英文用户、国外环境设计的。**

中国用户面临三大障碍：
- 网络障碍：需要代理才能稳定使用
- 语言障碍：英文交互，门槛高
- 模型障碍：只能用国外模型，成本高

灵犀 LingXiCode 从第一天就决定：

**为中国用户重新设计一个 AI 编程助手。**

不是照搬，不是汉化，而是重新思考中国用户真正需要什么。

---

## 灵犀独创的功能

以下功能，其他 AI 编程助手都没有做到灵犀的程度：

### 1. 三阶段执行系统（灵犀独创）

灵犀独创了 **Normal → Plan → Auto** 三阶段执行系统：

| 阶段 | 说明 |
|------|------|
| Normal | 简单问题，AI 直接回答 |
| Plan | 复杂任务，AI 先制定计划，弹出选项让用户确认方案 |
| Auto | 用户确认后，AI 按计划逐步执行 |

**为什么这很重要？**

其他产品的 AI 要么直接执行（用户无法干预），要么每步询问（用户太累）。

灵犀让用户在**计划阶段**就参与决策，确认方案后 AI 自动执行。用户既不会失控，也不会被每步打断。

**三种执行策略**（用户可随时切换）：

| 策略 | 适合场景 |
|------|---------|
| 自动执行 | 信任 AI，让它全自动完成 |
| 每步询问 | 严格审查，每一个操作都要确认 |
| 重大决策询问 | 平衡模式，危险操作才确认，普通操作自动执行 |

---

### 2. 技能自定义上传（灵犀独有）

灵犀内置 13 种专业技能：诊断 Bug、TDD 开发、原型设计、架构改进等。

**但更重要的是**：用户可以上传自定义技能包（.md 或 .zip 格式）。

这意味着：
- 团队可以创建统一的开发规范技能包
- 个人可以上传自己习惯的工作流程
- 不同项目可以用不同的技能组合

Claude Code 的 Skills 是官方定义的，用户无法自定义上传完整技能包。

---

### 3. 工具调用可视化（灵犀精心设计）

灵犀对 AI 的工具调用做了**完整的可视化设计**：

| 设计 | 说明 |
|------|------|
| 简洁格式 | 搜索显示 `🔍 关键词 (百度)`，编辑显示 `📝 文件名 +10 -5` |
| 可展开详情 | 点击展开查看完整内容或 diff 对比 |
| 文件名可点击 | 点击文件名直接打开 Monaco 编辑器预览 |
| 操作摘要 | AI 回复末尾自动生成本次操作摘要（修改/创建/读取的文件列表） |

其他产品只是简单列出工具调用，没有这种精心设计的可视化体验。

---

### 4. Monaco Editor 集成（VSCode 同款）

灵犀内置 Monaco Editor，这是 VSCode 使用的同款代码编辑器：

- 20+ 语言语法高亮
- 自定义深色主题
- 用户可手动修改 AI 生成的代码
- HTML 文件可在内置 iframe 中实时预览效果
- 语法错误实时提示

**这意味着**：用户不只是看 AI 写代码，还可以手动修改、纠正、完善。

---

### 5. 浏览器+文件混合标签页（灵犀独有）

灵犀的标签页系统可以同时管理：
- 网页（搜索结果、技术文档）
- 代码文件（预览、编辑）

并且支持**嵌入/独立窗口切换**：
- 标签页可以弹出为独立窗口（方便对照查看）
- 独立窗口可以嵌入回主窗口（方便统一管理）

---

### 6. 上下文环形可视化（灵犀独有）

灵犀用环形进度条实时显示 Token 使用百分比：
- 正常状态：蓝色
- 警告状态（70%）：黄色
- 满载状态（90%）：红色

点击环形图可打开详细状态面板：
- Token 使用量
- 对话轮数
- 摘要数量
- 压缩策略

其他产品都没有这种直观的上下文可视化。

---

### 7. AI 思考过程实时展示

灵犀支持 DeepSeek Reasoner 等推理模型的**思考过程实时展示**：

- AI 的推理过程实时显示在聊天区
- 可点击展开查看完整思考内容
- 让用户看到 AI 是怎么一步步得出答案的

---

### 8. 国内深度优化（灵犀核心优势）

| 优化项 | 说明 |
|--------|------|
| 搜索引擎 | 百度优先，自动依次尝试 百度 → 必应中国 → Bing → Google |
| 国产模型 | 智谱 GLM、DeepSeek、阿里千问、Kimi、豆包、文心一言、混元、星火等 |
| 无需代理 | 国内可直接使用 |
| 成本可控 | 可选择性价比更高的国产模型（DeepSeek、千问等） |

---

### 9. 代码翻译功能（即将推出，灵犀独有）

这是灵犀最关键的差异化功能：

**AI 将把代码翻译成通俗易懂的中文说明。**

```javascript
// 原代码
function calculateDiscount(price, memberLevel) {
  const rates = { vip: 0.8, gold: 0.9, normal: 1 }
  return price * rates[memberLevel]
}
```

```
// AI 翻译结果
这个函数的作用是计算折扣后的价格：
- 接收两个参数：原始价格和会员等级
- VIP会员打8折，金卡会员打9折，普通会员不打折
- 返回计算后的最终价格
```

**这将改变什么？**

| 人群 | 价值 |
|------|------|
| 不懂代码的人 | 能理解代码含义，参与讨论 |
| 产品经理 | 能参与代码评审，提出建议 |
| 新人接手项目 | 快速理解现有代码，降低交接成本 |
| 团队协作 | 技术和非技术人员能更好地沟通 |

**其他产品都没有这个功能。**

## 与其他产品的真正差异

| 对比维度 | Claude Code | Cursor | 灵犀 LingXiCode |
|----------|-------------|--------|-----------------|
| **定位** | CLI 工具，面向终端用户 | VSCode IDE，面向专业开发者 | **独立应用，面向中文用户** |
| **用户门槛** | 需熟悉终端命令 | 需安装 VSCode、熟悉 IDE | **无需安装 IDE，图形界面直接使用** |
| **执行控制** | 有权限模式，但无计划弹窗选择 | Agent 自动执行，无计划确认阶段 | **三阶段系统 + 弹窗选择方案** |
| **技能系统** | Skills 官方定义 | 无独立技能系统 | **13内置 + 自定义上传** |
| **工具可视化** | 文本列表 | 编辑器内显示 | **简洁格式 + 摘要 + 文件点击预览** |
| **文件编辑** | CLI 查看 | IDE 内编辑 | **Monaco Editor 独立预览窗口** |
| **窗口管理** | 无 | IDE 标签页 | **浏览器+文件混合 + 嵌入/独立切换** |
| **国内优化** | 无 | 无（翻墙+支付障碍） | **百度搜索 + 国产模型 + 无需代理** |
| **代码翻译** | 无 | 无 | **即将推出（独有）** |

## 灵犀适合谁？

| 人群 | 为什么选择灵犀 |
|------|---------------|
| **中国用户** | 百度搜索 + 国产模型 + 中文交互 + 无需代理 |
| **初学者** | 图形界面 + 不需要安装 VSCode + 不需要熟悉终端 |
| **企业用户** | 本地应用 + 数据不上传第三方 + 可控执行 |
| **团队协作** | 代码翻译让产品/运营也能理解代码 + 自定义技能包统一规范 |
| **成本敏感用户** | 可选择 DeepSeek、千问等高性价比国产模型 |
| **需要执行控制** | 三阶段系统 + 三种策略，让用户完全掌控 AI 操作 |

---

## 总结

灵犀 LingXiCode 不是照搬 Claude Code 或 Cursor。

它的设计理念是：

1. **为中国用户重新设计** — 百度搜索、国产模型、中文优先
2. **让用户掌控 AI** — 三阶段执行系统、三种策略选择
3. **让 AI 操作透明** — 工具可视化、操作摘要、上下文监控
4. **让非技术人员也能参与** — 代码翻译功能（即将推出）

**灵犀的价值不在于"功能更多"，而在于"为中国用户重新思考了 AI 编程助手应该是什么样子"。**
