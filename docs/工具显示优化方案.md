# 工具显示优化 + 任务总结功能方案

## 概述

优化灵犀 LingXiCode 的工具调用显示方式，从气泡框改为简洁格式，并新增任务完成摘要功能，提升用户对 AI 操作的感知和控制能力。

**状态：已完成实现 ✅**

---

## 一、简洁工具显示格式

### 1.1 显示规则

所有工具调用统一使用简洁格式，无气泡框，单行显示。

| 工具类型 | 图标 | 显示格式 |
|---------|------|---------|
| 搜索 | 🔍 | 🔍 —— 标题内容 (来源) |
| 编辑/修改 | 📝 | 📝 —— 文件路径 +新增行数(绿色) -删除行数(红色) |
| 读取 | 📖 | 📖 —— 文件路径:行数 |
| 写入/创建 | ✏️ | ✏️ —— 文件路径 (新建) |
| 执行命令 | ⚡ | ⚡ —— 命令内容 |
| 搜索文件 | 🔎 | 🔎 —— 模式 → 数量 |

### 1.2 示例

```
🔍 —— 防城港 天气预报 2026年5月19日 (baidu)
📝 —— src/config.ts +10 -5
📖 —— src/main.ts:1-50
✏️ —— src/newService.ts (新建)
⚡ —— npm install
🔎 —— **/*.ts → 15 文件
```

### 1.3 编辑行数计算

对比 `old_string` 和 `new_string`：
- `+N`：新增行数（绿色显示）
- `-M`：删除行数（红色显示）

## 二、工具展开详情

### 2.1 展开交互

每条工具末尾有 `>` 展开图标，点击展开详情。

### 2.2 编辑工具展开内容

展开后显示 diff：

```
┌─────────────────────────────────────────────────────⧉┐
│ 📝 src/filename.ts  +10 -5                          │
├───────────────────────────────────────────────────────┤
│ ▲ 新增代码（AI 准备替换的内容）                       │
│   ┌─────────────────────────────────────────────────┐ │
│   │ 绿色背景                                        │ │
│   │ import { newFunc } from './utils'              │ │
│   └─────────────────────────────────────────────────┘ │
├───────────────────────────────────────────────────────┤
│ ▼ 删除代码（将被替换的原内容）                        │
│   ┌─────────────────────────────────────────────────┐ │
│   │ 红色背景                                        │ │
│   │ import { oldFunc } from './utils'              │ │
│   └─────────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────────┘
```

### 2.3 其他工具展开内容

| 工具 | 展开后显示 |
|------|-----------|
| 搜索 | 搜索参数 + 结果摘要 |
| 读取 | 文件路径 + 内容（超过 100 行截断） |
| 写入 | 文件路径 + 写入内容摘要 |
| 命令 | 命令 + 执行结果（截断） |

## 三、⧉ 嵌入/独立窗口切换

### 3.1 功能说明

与浏览器窗口机制一致，点击 `⧉` 图标：
- **点击一次** → 内容变为独立子窗口
- **再点击** → 内容嵌入回右侧 webview 标签页

### 3.2 适用范围

- 编辑工具展开详情
- 文件预览窗口
- 浏览器标签页（现有功能）

---

## 四、文件预览窗口

### 4.1 触发方式

点击工具条中的文件路径（如 `src/config.ts`），右侧显示文件预览窗口。

### 4.2 功能

- 显示文件内容
- 支持用户编辑
- 有保存按钮
- 有 `⧉` 图标，支持嵌入/独立窗口切换

### 4.3 实现要点

| 模块 | 改动 |
|------|------|
| webview 标签页系统 | 扩展支持「文件标签页」类型 |
| IPC | 新增：读取文件内容、保存文件内容 |
| 前端 | 文件标签页渲染（代码编辑器样式） |

---

## 五、webview 视图系统说明

### 5.1 标签页容器概念

右侧 webview 区域是一个**标签页容器**，支持两种标签页类型：

| 标签页类型 | 内容 |
|-----------|------|
| 浏览器标签页 | 网页内容（搜索结果、文档页面等） |
| 文件标签页 | 文件内容预览、编辑界面 |

### 5.2 交互

- 多个标签页可共存（网页 + 文件混合）
- 点击标签页切换显示
- 每个标签页有关闭按钮
- 每个标签页有 `⧉` 图标（嵌入/独立切换）

## 六、任务完成摘要

### 6.1 功能说明

AI 任务完成、进行正文回复时，在回复末尾附加操作摘要。

### 6.2 摘要格式

```
┌─────────────────────────────────────┐
│ 📋 本次操作摘要                      │
├─────────────────────────────────────┤
│ 📝 修改文件 (3)                      │
│   • src/config.ts        [点击查看] │
│   • src/utils/helper.ts  [点击查看] │
│   • frontend/index.html  [点击查看] │
│                                     │
│ ✏️ 创建文件 (2)                      │
│   • src/api/newService.ts [点击查看]│
│   • docs/方案文档.md      [点击查看] │
│                                     │
│ 📖 读取文件 (5)                      │
│   • src/main.ts                     │
│   • package.json                    │
│   • ...                             │
│                                     │
│ ⚡ 执行命令 (2)                      │
│   • npm install                     │
│   • npm run build                   │
└─────────────────────────────────────┘
```

### 6.3 统计数据结构

```javascript
{
  modified: ['src/config.ts', 'src/utils/helper.ts'],
  created: ['src/api/newService.ts', 'docs/方案文档.md'],
  read: ['src/main.ts', 'package.json', ...],
  commands: ['npm install', 'npm run build']
}
```

### 6.4 文件名可点击

摘要中的文件名可点击，点击后打开文件预览窗口。
